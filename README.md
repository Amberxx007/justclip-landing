# JustClip landing page

A responsive marketing landing page for **JustClip**, a video-clipping app for creators.

## Preview locally

Open `index.html` in a browser, or serve this folder with any simple local web server.

## Included

- Responsive editorial-style landing page
- Phone mockup that plays the supplied WebM clip
- Video-to-clips workflow visual and multi-platform publishing cue
- Mobile layout, animated platform ticker, and clear calls to action

The video remains remotely hosted at the URL supplied for this project.
